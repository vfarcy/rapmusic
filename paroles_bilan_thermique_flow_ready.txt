Titre: Bilan Thermique (Flow Ready)
Tempo cible: 88 BPM
Cadence: 4/4, boom-bap narratif

[Guide de pose]
- 1 ligne = 1 mesure en moyenne.
- Les "//" indiquent une respiration courte.
- Les "..." indiquent un silence volontaire pour laisser le beat parler.

[Intro - 4 mesures]
Quatre-vingt-quatorze, le décor se dessine // pacte en noir et blanc
Dix-sept pour elle, vingt et un pour lui // ils jurent pour longtemps
Lui court vers le chiffre et la prime // pensant sauver le manque
Elle tient le foyer à bout de bras // mais le silence prend la planque

[Couplet 1 - 16 mesures]
Il rentre tard avec la paie // il pense: "j'assure la mission"
Mais l'amour manque d'air // quand il n'y a plus de transmission
Dans le nid, les filles grandissent // et son absence fait la loi
Spectateur de sa propre vie // il n'habite déjà plus chez soi
L'or du contrat s'effrite // le décor sonne creux
Il coche toutes les cases // mais il ne voit plus ses yeux
Il veut sceller l'union avec des billets // des plans, des garanties
Mais les cœurs n'ont pas de fiche de paie // ni clause de survie
Le confort n'efface pas l'orage // juste il le ralentit
Le manque revient la nuit // et c'est la nuit qui avertit
Il parle rendement, sécurité // projet à long terme
Elle parle chaleur, présence // et des gestes qui désarment
Deux langues dans la même maison // deux climats sous un toit
Le mur tient encore debout // mais le feu ne répond plus, déjà

[Refrain - 8 mesures]
C'est le bilan thermique d'un amour en hiver
Les cœurs se lézardent // les murs se perdent dans l'air
Trente-deux ans de sursis pour isoler le vide
Elle marche vers le jour // l'horizon devient limpide
Le contrat devient caduc // les sentiments s'exilent
Quand le béton s'effondre // reste le regard des filles
On voulait sauver la forme // on a perdu le sens
C'est le bilan d'une vie // et le prix de l'absence

[Couplet 2 - 16 mesures]
Puis la machine s'enraye // grand court-circuit intérieur
Burn-out professionnel // le "pilier" n'a plus de moteur
Le protecteur chancelle // l'image tombe du cadre
Pour elle c'est le séisme // le réel devient plus dur à tenir
Alors elle blindera l'avenir // deux refuges, deux pierres
Comme on met un casque au cœur // quand le futur fait peur
Briques contre la peine // assurance contre le sort
Pendant qu'il panse son orgueil // en jouant encore plus fort
Mais la loi change le terrain // nouveau climat, nouvelles règles
Les nids prévus pour plus tard // deviennent des pièces fragiles
Il faut vendre avant la casse // avant le gouffre, avant le bras
Mais en vendant ces murs-là // c'est son ciel qu'il brise, là
A table, les silences coupent // plus tranchants qu'un jugement
Ils ne se parlent plus d'amour // seulement de financement
Tout est propre sur le papier // tout est mort dans la voix
Il reste les faits, les chiffres // et ce que personne ne reçoit

[Couplet 3 - 16 mesures]
Elle se sent dépouillée // mise à nu par l'orage
Ce n'est plus une affaire d'argent // c'est la fin du voyage
A cinquante-cinq printemps // elle veut respirer demain
Lui, cinquante-neuf, regarde la mer // mais ne voit plus le chemin
Le verdict tombe à table // net, comme un couperet
Trente-deux ans de mariage // en une phrase, c'est terminé
Il est triste et coupable // déçu par la sentence
Lui qui croyait leur deal grave // en clauses d'équivalence
Mais les comptes d'amour n'ont pas de bilan comptable
La raison du plus fort // n'est plus du tout rentable
Le rideau tombe enfin // sur ce drame invisible
Elle reprend sa vie // lucide, debout, invincible
Lui reste face aux ruines // du rôle qu'il a porté
Comprend trop tard une chose // aimer, c'est être à côté
Pas juste payer la facture // ni promettre en grand angle
Mais tenir dans le quotidien // quand le cœur devient fragile
